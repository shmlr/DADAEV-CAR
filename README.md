# DADAEV CAR

Мобильный статический сайт автопроката по мотивам предоставленного видеореференса. Работает без сборки и сервера: **заставка → каталог → дата аренды → форма → проверка → подтверждение → локальная история**.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере, либо загрузите весь каталог в корень публичного репозитория GitHub.
3. Для GitHub Pages откройте **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save**. После публикации проверьте фактический адрес, который покажет GitHub.

## Что уже работает

- Переключение трёх демонстрационных автомобилей: Toyota Corolla, Toyota Prius, Toyota RAV4 (кнопки, свайпы и стрелки клавиатуры).
- Выбор даты получения и возврата в календаре, ввод **ДД.ММ.ГГГГ**, например `30.12.2022`. Для нового бронирования прошлые даты запрещены; возврат должен быть позже получения.
- Форма с обязательными полями фамилии, имени и телефона, а также проверкой согласий.
- Просмотр заявки, экран подтверждения, копирование заявки, локальная история и экспорт `.csv` / `.json`.
- Адаптивный интерфейс для смартфона и компьютера.

## Важные ограничения

**Это демонстрационный MVP, а не работающая система подтверждённого бронирования.** Фактический парк, технические характеристики, наличие и стоимость машин пока не подтверждены. Цены поэтому указаны «По запросу». Фотографии и модели взяты из предоставленного видеопримера; перед коммерческим запуском согласуйте права на изображения и реальные данные машин. Информация о Corolla из видеопримера не является подтверждением характеристик автопарка DADAEV CAR.

Без backend заявка **остаётся в `localStorage` конкретного браузера**. Сервер не получает данные; менеджер не узнаёт о заявке автоматически, даже если показан экран подтверждения. Для централизованного сбора нужен защищённый сервер/API или согласованная интеграция.

Поля серии, номера и срока действия водительского удостоверения показаны для соответствия референсу, но **не сохраняются, не экспортируются и не передаются через WhatsApp**. Не используйте GitHub Pages для хранения документов или секретов; для коммерческого сбора персональных данных требуется отдельная защищённая обработка и юридически корректные тексты/согласия.

```js
window.DADAEV_CONFIG = {
  whatsappNumber: "79285015533"

```

Внешняя ссылка «Полный опубликованный автопарк» ведёт на [dadaevcar.ru/classes.asp](https://dadaevcar.ru/classes.asp), где размещены 18 карточек на момент проверки 12.11.2026. Состав не удалось сверить с WhatsApp Business: WhatsApp-каталог нельзя получить через обычный публичный просмотр. **Три демонстрационные машины на этом сайте не следует считать подтверждённым парком DadaevCar.**

После этого появятся кнопки перехода в WhatsApp с подготовленным сообщением. **Само сообщение пользователь отправляет в WhatsApp**, сайт не может подтвердить его доставку или бронирование. Не прописывайте в публичных файлах токены/API-ключи.
